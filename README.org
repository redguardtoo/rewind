* Rewind
Resume Emacs last `completing-read` session with saved input.

Inspired by `ivy-resume` in [[https://github.com/abo-abo/swiper/blob/master/ivy.el][ivy.el]] but uses only native Emacs API and has no third party package dependency.

* Install
You could place =rewind.el= under [[https://www.emacswiki.org/emacs/LoadPath][Load Path]].

* Set up
Insert below code into =~/.emacs.d/init.el= to setup key bindings:
#+BEGIN_SRC lisp
(require 'rewind)
(rewind-mode 1)
#+END_SRC

* Usage
Run =M-x rewind-resume= to re-run original command and restore the saved completion arguments and minibuffer input.
